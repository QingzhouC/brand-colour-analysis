# Brand Colour Analysis

A computational colour research workflow inspired by modern design systems.

## Overview

This project explores how brand colours can be analysed through image collection, colour extraction and clustering.

## Workflow

100 brand-related images
↓
Colour extraction
↓
RGB to Lab conversion
↓
K-Means clustering
↓
Colour distribution analysis
↓
Brand colour validation

## Technologies

- Python
- Pillow
- NumPy
- Pandas
- Scikit-learn
- Scikit-image
- Matplotlib

## Method

The system extracts dominant colours from collected images and clusters them in Lab colour space to identify visual colour patterns.
